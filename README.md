# Tiny Stack VM

Tiny stack virtual machine in TypeScript (`main.ts`). Runs make.fun tiny-stack ISA programs: 32-bit wrapping integers, a 256-value data stack, a 64-value call stack, 256 words of memory, and traps with their own exit codes.

Run with the kit grader, or `node main.ts` with `MAKEFUN_INPUT_DIR` and `MAKEFUN_OUTPUT_DIR` set.

Practice score (kit practice set, 40 instances): 1,000,000.
